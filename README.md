## Ім'я за кодом

Є різниця між написанням програмного забезпечення та розумінням того, яким воно має бути.

Перше вимагає знання мови. Друге — способу мислення, якого не здатна навчити жодна мова програмування.

Я створюю системи, розробляю інструменти та перетворюю ідеї на працюючі рішення. Для мене важливі точність, продумана архітектура й код, який залишається зрозумілим навіть тоді, коли перший успішний запуск давно позаду.

Мої проєкти продовжують розвиватися. Мої стандарти не чекають, поки вони їх наздоженуть.
